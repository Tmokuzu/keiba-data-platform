# 中央競馬向け特徴量設計

## 目的と原則

目的は、複勝の `place_prob_final` と期待値を、予測時点で入手できる情報だけで改善することです。
特徴量は次の6群に整理します。

```text
能力 × 近走状態 × コース・距離適性 × 展開 × 馬場・当日バイアス × 騎手・厩舎 × 市場
```

重要な原則は次のとおりです。

- 各特徴量は対象レースの発走時点までに確定している情報だけを使う。
- 同日の馬場バイアスは、対象レースより前に確定したレースだけを使う。
- 相手馬の次走成績・未来のレース結果・最終確定後オッズは予測特徴量に使わない。
- すべての導入は時系列Walk-Forwardで、既存モデルとの差分を検証する。

## 現在のデータで実装できる特徴量

`races`、`entries`、`results`、`horse_results_history` に既にある列から、次を安全に作れます。

| 群 | 特徴量 | 算出 | 状態 |
| --- | --- | --- | --- |
| 能力 | 通算・直近3/5走の複勝率、平均着順 | 対象日より前の同一馬結果 | 実装済み |
| 近走状態 | 直近3走の平均上がり3F、休養日数 | 過去結果とレース日 | 実装済み |
| 適性 | 競馬場・芝ダ・馬場・距離帯の過去複勝率と出走数 | 馬 × 条件の過去結果 | 実装済み |
| 条件変化 | 距離、斤量、馬体重、騎手、枠、クラスの前走差 | 今回値と直近過去値 | 次段階 |
| 展開 | 4角位置、4角から着順への変化、先行率 | `corner_order` と過去結果 | 次段階 |
| 市場 | 複勝オッズの市場確率、正規化確率、レース内順位 | 締切前オッズ | 一部実装済み |

市場特徴量は、レース前に取得した時刻付きオッズがある場合だけ信頼します。過去に後から取得した
最終オッズを学習に使うと将来情報になるため、JV-Linkの過去取込では保存しません。

## 目標となる特徴量セット

### 1. 能力・近走状態

| 特徴量 | 定義 | 必要データ |
| --- | --- | --- |
| 馬場補正走破タイム指数 | 過去走の走破タイムを、同コース・距離・馬場・開催日の標準タイムとの差へ変換 | `finish_time_ms`、標準タイム集計 |
| 着差指数 | 着差を距離・馬場で標準化した値 | 数値化した `margin` |
| 最高・平均パフォーマンス | 直近6～10走の最大値、直近3/5走の平均・傾き | 上記指数 |
| 上がり順位・上がり差 | 同レース内での上がり3F順位と平均との差 | `last_3f` と全出走馬結果 |
| 位置取り変化 | 1～4角と着順の順位変化 | 分割したコーナー通過順 |
| 馬体状態 | 前走比、過去好走時平均との差、極端な増減フラグ | `body_weight`、`body_weight_diff` |
| 休養・間隔 | 前走からの日数、連闘・休み明け区分 | `race_date` |

### 2. コース・距離・条件適性

中央競馬では「東京芝1600」のように競馬場と距離を分けず、組合せで集計します。

| 特徴量 | 定義 |
| --- | --- |
| コース距離複勝率 | 馬 × 競馬場 × 芝ダ × 距離の過去複勝率・出走数 |
| 回り適性 | 左右回り、直線・小回り区分ごとの過去成績 |
| 馬場適性 | 良・稍重・重・不良ごとの成績とサンプル数 |
| 距離変更 | 延長／短縮量、前走距離との差、距離変更後の過去成績 |
| クラス変化 | レースクラスの順序尺度による昇級・降級・同級フラグ |
| 枠 × 脚質 | 枠順と推定脚質の交互作用 |

サンプルが少ない条件別率はそのまま使わず、全体成績へ縮約する平滑化を行います。例えば、
コース距離複勝率は `（的中数 + 事前平均 × 強度）/（出走数 + 強度）` とします。

### 3. 脚質・展開

| 特徴量 | 定義 | 時点 |
| --- | --- | --- |
| 逃げ・先行・差し率 | 過去の1角／4角順位を頭数で正規化した比率 | 過去レースのみ |
| 推定テン速度 | 1角順位、前半ラップ、直近先行率から算出 | 過去レースのみ |
| 同型馬数 | 今回出走馬のうち、逃げ・先行推定馬の数 | 今回出走表＋過去履歴 |
| ペース圧 | 同型馬数、内枠先行馬数、距離・コース特性の組合せ | 今回出走表＋過去履歴 |
| 脚質相性 | 推定ペースに対する各馬の過去成績 | 過去レースのみ |

「推定隊列」は説明用の順位であり、モデルには順位そのものではなく、先行確率・同型数・
想定ペース圧などの連続値を入力します。

### 4. 当日馬場・バイアス

当日情報は発走前に利用可能なものだけを `temp/` または予測ログに保存します。学習用core層には
入れません。

| 特徴量 | 定義 | 利用条件 |
| --- | --- | --- |
| 当日馬場状態 | 良・稍重・重・不良 | 発表済み |
| 当日ペース・前残り率 | 同日・同場・同芝ダで、対象レースより前に確定した結果から算出 | 前レース確定後のみ |
| 内外バイアス | 枠番を頭数で正規化し、前レースまでの好走率を平滑化 | 前レース確定後のみ |
| 当日標準タイム差 | 同条件の当日走破タイムと過去標準との差 | 同条件の前レースがある場合のみ |

当日レースがまだ一つも確定していない場合、当日バイアスは欠損として扱い、過去のコース傾向へ
フォールバックします。

### 5. 騎手・厩舎

| 特徴量 | 定義 |
| --- | --- |
| 騎手のコース距離複勝率 | 騎手 × 競馬場 × 芝ダ × 距離の過去率（平滑化あり） |
| 騎手交替 | 継続騎乗、乗替り、過去の馬×騎手組合せ成績 |
| 厩舎直近状態 | 厩舎の直近30日・90日の複勝率 |
| 騎手×厩舎 | 組合せの過去複勝率。小標本では全体率へ縮約 |

高カーディナリティなIDをそのまま強く使い過ぎないよう、IDなし・集計値のみのアブレーションを
毎回比較します。

### 6. 市場・期待値

| 特徴量 | 定義 |
| --- | --- |
| 市場複勝確率 | `1 / odds_place_min` |
| 正規化市場確率 | 同一レース内の市場確率合計で正規化 |
| オッズ順位・変化 | 順位、直近スナップショットとの差・変化率 |
| モデル優位性 | `place_prob_final - market_place_prob` |

オッズ変化は複数の `raw_odds` スナップショットが蓄積できてから追加します。単一時点のオッズを
変化として代用しません。

## 取込・スキーマ拡張

JV-Linkから受け取った全レコードは、種別ごとの正規化前に `raw_jv_records` へ保存する。
これは未対応レコードを捨てず、仕様変更・固定長位置の再検証・追加特徴量のための再処理を可能に
するためである。対象は `RACE` だけでなく、`DIFN`（UM/KS/CH等）、`SNPN`（CK）、`SLOP`（HC）、
`WOOD`（WC）、`BLDN`（HN/SK/BT）、`COMM`（CS）、`MING`（DM/TM）とする。

精度改善の優先度に沿って、次の順で拡張します。固定長レコードの位置はJV-Data仕様書と実レコードの
両方で確認してから実装します。

1. **P0: 現在のRA/SE/HR/O1を検証**
   レースID、馬番、距離、馬場、4角、上がり3F、着差、払戻の欠損率を品質レポート化します。
2. **P1: `results` の数値列を追加**
   `finish_time_ms`、`margin_seconds`、`corner_1`～`corner_4`、可能なら前半3F・ラップを
   raw/core両層に追加します。文字列を学習時に都度解析しません。
3. **P2: 派生集計層を追加**
   走破タイム指数、条件別の平滑化率、騎手・厩舎集計を、レース日基準のas-of計算で作ります。
4. **P3: 当日特徴量を追加**
   オッズ変化、当日バイアス、馬体重確定値を `temp/` と予測ログへ保存します。
5. **P4: 追加データソースを検討**
   血統、調教、取消・馬具などは、取得時点とライセンスを確認してから追加します。

## 明確に使わない情報

以下は予測時点に存在しないか、検証を不正に楽観化するため、特徴量に使いません。

- 前走で先着・敗戦した馬の**次走以降**の成績
- 対象レースより後に確定した同日レースの結果
- 過去レースを後から取得した最終オッズ
- 予測対象レースの確定着順、払戻、確定後馬場差

## 検証基準

新特徴量は、追加前モデルと同じ時系列分割で以下を比較します。

1. AUC、LogLoss、Brier score
2. Walk-Forwardの各年におけるROI・買い目数・最大ドローダウン
3. 特徴量群を外したアブレーション
4. 市場特徴量あり／なし、IDあり／なしの比較
5. 当日予測ログでの入力時刻・オッズスナップショット監査

精度改善は単一のテスト期間では採用せず、複数年のWalk-Forwardで安定して改善した場合だけ採用します。
